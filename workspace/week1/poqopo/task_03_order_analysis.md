# Task 03: CSV 주문 데이터 분석 프로그램 구현

## 실행 지시문

다음 주문 데이터를 분석하는 Python 프로그램을 작성하라.

요구사항:

1. CSV 데이터를 읽어 주문별 매출을 계산한다.
2. `취소` 상태 주문은 매출에서 제외한다.
3. 중복 주문 ID는 한 건만 반영한다.
4. 카테고리별 총매출과 최고 매출 고객을 출력한다.
5. 잘못된 금액·수량·날짜 데이터는 프로그램을 중단하지 않고 별도로 기록한다.
6. 테스트 데이터를 직접 만들고 프로그램을 실행해 결과를 검증한다.

```csv
order_id,customer,category,price,quantity,status,date
A001,김민수,전자기기,120000,2,완료,2026-10-01
A002,이지수,도서,18000,3,완료,2026-10-02
A003,박준호,전자기기,85000,1,취소,2026-10-03
A001,김민수,전자기기,120000,2,완료,2026-10-01
A004,최서연,생활용품,abc,2,완료,2026-10-04
A005,김민수,도서,22000,-1,완료,2026-10-05
```

|---|---:|---:|---|

| 사용한 Tool | `read`, `write`, `present` | `functions.bash` | 사용 Tool 구성이 다름 |
| Tool 호출 횟수 | 5회 | 1회 | Minimal이 4회 적음 |

| 오류 데이터 처리 정확성 | 더 robust한 처리 | 상대적으로 제한적 | Standard가 우수 |

## 결과물 비교

- **Minimal:** `task3_minimal.py`를 작성하고 파일 생성 및 크기를 확인했다. Tool 호출과 Token 사용량은 적었지만, 결과물의 검증 범위와 오류 처리의 robustness는 상대적으로 제한적이었다.
- **Standard:** 테스트용 CSV 파일들을 추가로 제공하고, 생성된 결과물을 검증했다. 오류 데이터에 더 robust하게 대응하는 결과를 얻었다.
- **종합:** Minimal은 더 빠르고 적은 Tool·Token으로 기본 결과를 만들었고, Standard는 더 많은 리소스를 사용해 테스트 자료와 오류 대응까지 포함한 완성도 높은 결과를 만들었다.

## 기록 방법

Standard와 Minimal에서 동일한 지시문을 각각 실행하고, 생성된 파일·실행 결과·테스트 로그를 기준으로 빈칸을 채운다.
