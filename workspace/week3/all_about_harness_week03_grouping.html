1. Plugin과 Plugin Group

Plugin은 기능을 등록하고, Group은 여러 Plugin을 하나의 구성으로 묶는다.

Plugin
기능을 구현하고 Tool·Service 등을 등록하는 코드
search-tool.ts
Plugin Group
여러 Plugin을 함께 묶어 관리하는 구성
cordis:group
Agent Preset
Agent에 연결할 Plugin 구성 목록
plugins: [...]
이번 주 목표   Plugin 2개 이상 → Group 1개 → Agent Preset 1개

2. Plugin Group은 어떻게 구성할까?

Plugin을 개별적으로 나열할 수도 있고, 관련된 기능을 하나의 그룹으로 묶을 수도 있다.

그룹 없이

Preset에 Plugin을 각각 등록

AGENT PRESET
Search Plugin
Summary Plugin

그룹으로 묶기

관련된 Plugin을 하나의 구성 안에 배치

AGENT PRESET
Research Group
Search Plugin
Summary Plugin
그룹 자체가 새로운 Tool을 만드는 것은 아니야. 실제 기능은 그룹 안의 Plugin이 등록해.

3. 왜 Plugin을 묶을까?

관련된 기능을 함께 구성하고, 원하는 Preset에 연결할 수 있다.

01
역할별 구성
검색과 요약을 Research Group으로,
파일 처리 기능을 File Group으로 구분
02
함께 관리
하나의 그룹에 속한 Plugin을 함께
로드하거나 언로드하는 구성
03
Preset 구성
하나의 Agent Preset 안에 여러
Plugin Group을 조합할 수 있음
핵심: Plugin을 하나씩 만들고, 관련된 기능을 묶어 하나의 Agent에 연결한다.

Week 03 · Preset 구성 예시

Agent Preset의 plugins 목록에 Group을 추가

AGENT PRESET · YAML 예시
- id: preset-group-lab
  name: '@deepseek-ai/dsh-agent-preset'
  config:
    id: group-lab
    plugins:
      - id: research-group
        name: cordis:group
        group: true
        config:
          - name: './plugins/search-tool.ts'
          - name: './plugins/summary-tool.ts'

확인할 것

1. Group에 두 Plugin이 등록됐는가?

2. Agent가 두 기능을 모두 호출했는가?

3. 실행 로그와 결과가 남았는가?

경로와 Plugin 이름은 예시야. 실제 설치 위치와 실행 환경에 맞게 수정하면 돼.
