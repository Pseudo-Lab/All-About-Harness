# Task 02: 원·달러 환율 조회 및 환산

## 실행 지시문

오늘의 원·달러 환율을 확인한 뒤, 100달러·500달러·1,000달러를 원화로 환산하라. 사용한 환율의 기준 시각과 출처를 함께 제시하고, 환율 적용 과정과 최종 금액을 표로 정리하라.

## Standard vs Minimal 비교 결과

| 비교 항목 | Standard | Minimal | 차이/비고 |
|---|---:|---:|---|
| 작업 성공 여부 | 성공 | 성공 | 동일 |
| 실행 응답시간 | 23초 | 17초 | Minimal이 6초 빠름 |
| 사용한 Tool | `web_search`, `web_fetch` | `functions.bash` | 사용 Tool이 다름 |
| Tool 호출 횟수 | 4회 | 3회 | Minimal이 1회 적음 |
| 참조한 외부 출처 수 | 최종 답변 기준 1개 | 최종 답변 기준 1개 | 동일 |
| 실행 순서 | `web_search` → `web_fetch`(Investing.com, 403) → `web_search` → `web_fetch`(ExchangeRate-API) | ① 환율 API 조회 및 시간 확인 → ② 기준 시각·환율 재확인 → ③ 환산 금액 계산 | Standard는 출처 오류 후 재검색 |
| 입력 Token | 12,222 | 4,241 | Minimal이 7,981 Token 적음 |

| 환율 최신성·계산 정확성 | 정확 | 정확 | 환율·환산 결과 동일 |

## 실행 결과

### Minimal

확인 시점 기준 오늘은 **2026년 10월 11일**입니다.  
**1 USD = 1,341.69027 KRW**를 적용했습니다.

- **기준 시각:** 2026년 10월 11일 09:02 KST
- **출처:** [ExchangeRate-API, USD 기준 실시간 환율](https://open.er-api.com/v6/latest/USD)

| 달러 | 적용 과정 | 원화 환산액 |
|---:|---:|---:|
| $100 | 100 × 1,341.69027 | **₩134,169** |
| $500 | 500 × 1,341.69027 | **₩670,845** |
| $1,000 | 1,000 × 1,341.69027 | **₩1,341,690** |

원화 금액은 소수점 이하를 반올림했습니다. 실제 은행 환전액은 환전 수수료와 적용 환율에 따라 달라질 수 있습니다.

### Standard

확인 시점 기준 환율은 **1달러 = 1,341.69027원**입니다.

- **기준 시각:** 2026년 10월 11일 09:02:31 KST (API 제공 시각: 00:02:31 UTC)
- **출처:** [ExchangeRate-API USD 기준 환율](https://open.er-api.com/v6/latest/USD)

| 달러 금액 | 적용 과정 | 원화 환산액 |
|---:|---:|---:|
| $100 | 100 × 1,341.69027 | **134,169원** |
| $500 | 500 × 1,341.69027 | **670,845원** |
| $1,000 | 1,000 × 1,341.69027 | **1,341,690원** |

원화 금액은 1원 단위로 반올림했으며, 실제 환전 시에는 금융기관의 매매기준율·수수료에 따라 달라질 수 있습니다.

## 기록 방법

Standard와 Minimal에서 동일한 지시문을 각각 실행한 뒤, 실제 응답과 실행 로그를 기준으로 빈칸을 채운다. 두 실행에서 동일한 실행 시각을 기록하고, 환율 값과 계산 결과가 일치하는지 확인한다.
