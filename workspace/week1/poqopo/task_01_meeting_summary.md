# Task 01: 회의록 요약 및 Action Item 추출

## 실행 지시문

다음 회의록을 읽고 ① 핵심 결정사항 3개 이하, ② 담당자별 Action Item, ③ 확인이 필요한 미결사항을 표로 정리하라. 회의록에 없는 내용은 추측하지 말고 `미정`으로 표시하라.

> 다음 주 월요일까지 랜딩 페이지 초안을 완성하기로 했다. 디자인은 지수가 담당하고, 민수는 사용자 문구를 정리한다. 다만 최종 공개일은 아직 정하지 못했다. 개발팀은 로그인 오류를 이번 주 금요일까지 재현해 원인을 공유하기로 했다. 다음 회의는 목요일 오후 3시에 진행한다.

## 실행 결과 내용

### ① 핵심 결정사항

| 결정사항 |
|---|
| 다음 주 월요일까지 랜딩 페이지 초안을 완성한다. |
| 디자인은 지수, 사용자 문구 정리는 민수가 담당한다. |
| 개발팀은 이번 주 금요일까지 로그인 오류를 재현하고 원인을 공유한다. |

### ② 담당자별 Action Item

| 담당자 | Action Item | 기한 |
|---|---|---|
| 지수 | 랜딩 페이지 디자인 | 다음 주 월요일까지 |
| 민수 | 사용자 문구 정리 | 다음 주 월요일까지 |
| 개발팀 | 로그인 오류 재현 및 원인 공유 | 이번 주 금요일까지 |
| 미정 | 다음 회의 참석 및 후속 논의 | 목요일 오후 3시 |

### ③ 확인이 필요한 미결사항

| 미결사항 | 상태 |
|---|---|
| 랜딩 페이지 최종 공개일 | 미정 |

## 기록 방법

Standard와 Minimal에서 동일한 지시문을 각각 실행한 뒤, 실제 응답과 실행 로그를 기준으로 빈칸을 채운다. 특히 외부 Tool 없이도 두 mode가 정확한 결과를 내는지 비교한다.
